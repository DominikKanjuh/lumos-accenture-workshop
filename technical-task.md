# Case 1 — Bug Fixing Agent

The client's development team loses valuable time on recurring bugs. Build an AI agent that autonomously resolves a reported bug in the provided code base.

## Your task
- Build an agent that analyzes the bug report and locates the root cause
- Let it use the repository's context: wiki, code, conventions and tests
- Have it implement a fix that follows the team's coding standards
- Validate the fix with existing or new tests

## What we look for
- A correct, working fix
- Smart use of the repository context
- Transparent agent reasoning and human review
